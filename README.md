# Nafis Wardrobe Website

## About the Project

Nafis Wardrobe is a fashion website interface created using HTML and CSS. It focuses on presenting fashion-related content with a clean layout and simple navigation.

## Features

* Home section
* About section
* Navigation menu
* Fashion-focused webpage design
* CSS styling and page layout

## Technologies Used

* HTML
* CSS

## Project Files

* `index.html` – Main webpage
* `style.css` – Website styling

## Purpose

This project was developed to practise frontend development, website layout, navigation, and CSS styling.
